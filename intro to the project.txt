● Project Overview: Spendly - Expense Tracker

  This is a Flask-based personal expense tracking web application called
  "Spendly". It's structured as a learning/teaching project where students
  implement features step-by-step.

  Architecture

  ┌───────────┬─────────────────────────────┐
  │ Component │         Technology          │
  ├───────────┼─────────────────────────────┤
  │ Backend   │ Flask 3.1.3                 │
  ├───────────┼─────────────────────────────┤
  │ Database  │ SQLite (via database/db.py) │
  ├───────────┼─────────────────────────────┤
  │ Frontend  │ HTML templates + CSS/JS     │
  ├───────────┼─────────────────────────────┤
  │ Testing   │ pytest + pytest-flask       │
  └───────────┴─────────────────────────────┘

  Current Implementation

  Routes (app.py):
  - / - Landing page with hero section and feature showcase
  - /register - User registration page
  - /login - User login page
  - /logout - Placeholder (Step 3)
  - /profile - Placeholder (Step 4)
  - /expenses/add - Placeholder (Step 7)
  - /expenses/<id>/edit - Placeholder (Step 8)
  - /expenses/<id>/delete - Placeholder (Step 9)

  Database (database/db.py):
  - Currently a skeleton file with comments indicating students should
  implement:
    - get_db() - SQLite connection helper
    - init_db() - Table creation
    - seed_db() - Sample data seeding

  Features (Planned)

  1. User authentication (register/login/logout)
  2. Expense logging with category, amount, date, description
  3. Spending pattern analysis with category breakdowns
  4. Time-period filtering (weekly, monthly, custom ranges)
  5. Monthly summaries and visualizations

  Project Structure

  expense-tracker/
  ├── app.py              # Main Flask application
  ├── database/
  │   └── db.py           # Database layer (to be implemented)
  ├── templates/          # HTML templates
  │   ├── base.html
  │   ├── landing.html
  │   ├── login.html
  │   └── register.html
  ├── static/
  │   ├── css/style.css
  │   └── js/main.js
  └── requirements.txt

  This appears to be an educational project where the core structure is set up,
  but students fill in the implementation gaps through guided steps.
